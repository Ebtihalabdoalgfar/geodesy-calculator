# 📐 Geodesy Calculator

A Python-based geodesy calculator designed to perform a collection of common geodetic computations through a simple graphical interface.

## ✨ Features

- 🌍 WGS84 ellipsoid parameters
- 📍 Cartesian to geodetic coordinate conversion
- 🧭 Local East-North-Up (ENU) coordinates
- 🔄 Helmert transformation
- 📐 Spherical trigonometry calculations
- 📏 Orthometric height calculation
- 🖥️ Graphical user interface using Tkinter

## 🛠️ Built With

- Python
- Tkinter
- Mathematical and geodetic computations

## 🎯 Project Goal

The project was developed to connect theoretical geodesy concepts with programming by turning commonly used geodetic calculations into an interactive Python application.
